# 技术选型说明

## 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| React | 19.x | UI 框架 |
| TypeScript | 5.x | 类型安全 |
| Vite | 6.x | 构建工具 |
| Tailwind CSS | 3.x | 原子化 CSS 框架 |
| React Router | 7.x | 页面路由 |

## 为什么选这些

### React
- 最流行的前端框架，中文资料丰富
- 组件化开发，适合逐步迭代
- 国内岗位需求大

### TypeScript
- 在写代码时就能发现类型错误，减少 bug
- 提供智能提示，降低记忆负担

### Vite
- 开发服务器启动极快
- 开箱即用的 React + TypeScript 支持

### Tailwind CSS
- 不需要命名 class、不用在多个 CSS 文件间跳转
- 内置设计约束（间距、颜色有统一尺度），自然形成一致性
- 响应式、hover 状态等写起来非常简洁

### React Router
- React 生态的标准路由方案

## 为什么不做后端

- 纯前端 + localStorage 即可满足需求
- 不需要服务器、数据库、用户系统
- 数据存在用户自己的浏览器中，隐私安全
- 部署仅需静态文件托管，成本为零
