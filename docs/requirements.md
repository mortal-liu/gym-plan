# 需求文档

## 项目概述

Gym Plan — 一款极简风格的健身训练记录 Web 应用。用户可以选择训练类型（推/拉/蹲），记录每个动作的组数、次数和重量，并随时查看历史训练记录。

## 用户故事

### 1. 训练日选择
- 打开应用后，看到三个训练日选项：推日、拉日、蹲日
- 点击任一选项进入对应的训练记录页面

### 2. 训练记录
- 进入训练页后，看到该训练日对应的预设动作列表
- 每个动作可以展开，添加多组记录
- 每组记录包含：重量(kg)、次数
- 可以动态添加或删除组
- 点击保存后，整个训练记录保存到本地

### 3. 历史查看
- 可以从首页进入历史页面
- 按日期倒序查看所有训练记录
- 可以按训练类型（推/拉/蹲）筛选
- 点击某条记录可展开查看详情

## 功能范围

### 本期（MVP）
- 推/拉/蹲三个训练日，每个训练日约6个预设动作
- 记录组数、次数、重量
- 本地存储（localStorage）
- 历史记录查看与筛选

### 暂不做
- 自定义添加/删除动作
- 用户账号系统
- 云端同步
- 数据导出
- 训练计划/模板
